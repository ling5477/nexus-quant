## 1. 使用规则

- 仅在新的“当前阶段”正式启动后，按该阶段名称替换标题与上下文。
- 任何契约 / 表结构 / 状态机变化，都必须同步记录到 current 入口与对应 gate 卷宗文档。
- 历史阶段不要回填到本模板，历史事实应写入各自 `docs/gates/gate-*/WORK.md`。
