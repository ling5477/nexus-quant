# GateF PR_SPLIT_PLAN

原则：

- 一个 PR 只解决一类问题
- 先文档、再骨架、再主链、再评估
- 不把 GateF 做成一次性巨型 PR

---

## 1. 执行顺序总览

- [x] GateF-DOC-1：研究 / 回测 / 评估能力开工基线
- [x] GateF-1：研究 / 回测配置与运行骨架
- [x] GateF-2：市场数据输入与回测运行主链
- [x] GateF-3：模拟成交 / 持仓 / PnL
- [x] GateF-4：评估指标与结果查询
- [x] GateF-5：研究产物与执行域接口收口

冻结说明：

- GateF 已按原 PR 拆分顺序完成
- 本文件保留为冻结卷宗，不再表达“待做”语义

---

## 2. GateF-1：研究 / 回测配置与运行骨架

目标：

- 定义 `ResearchConfig / BacktestConfig / BacktestRun`
- 建立最小运行骨架

不做：

- 市场数据接入
- 模拟成交
- 评估指标

---

## 3. GateF-2：市场数据输入与回测运行主链

目标：

- 明确市场数据输入边界
- 建立最小 backtest run 执行主链

不做：

- 复杂数据平台
- 外部数据接入大而全适配

---

## 4. GateF-3：模拟成交 / 持仓 / PnL

目标：

- 建立 `sim_order / sim_trade / sim_position / sim_pnl`

不做：

- 实盘订单复用
- GateE 执行链重写

---

## 5. GateF-4：评估指标与结果查询

目标：

- 输出评估指标
- 提供最小回测结果查询面

不做：

- BI 报表平台
- 复杂可视化系统

---

## 6. GateF-5：研究产物与执行域接口收口

目标：

- 明确研究产物到执行域的接口
- 定义哪些对象只能映射不能共用

不做：

- 回头补 GateE 遗留执行债务
