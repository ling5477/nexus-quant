# Roadmap（V1 → V3）

> 目的：把迭代边界写清楚，避免“模块先堆起来，闭环后补”。

---

## V1：数字货币（当前）

### v1.0（Gate A）— 正确性底座（文档+骨架）
- 冻结域模型、状态机、事件契约、数值精度策略、恢复口径
- Postgres/Flyway 迁移规划
- auth/gateway 骨架与 traceId 透传约定
- 模块与依赖方向冻结（含 nq-app 启动载体）

### v1.1（Gate B）— 单交易所现货打通（实现）
- 交易所适配：OKX 或 Binance（REST + WS）
- 最小策略（示例）+ 风控拦截 + 下单闭环
- 账本写入 + 对账口径初版
- 观测：延迟、拒单率、重连次数等指标

### v1.2（Gate C）— 双交易所 + 模拟盘/回放增强
- Adapter API 稳定，多交易所并行
- 模拟盘（交易所模拟 or 本地撮合）
- 回放/恢复演练自动化（CI）

### v1.x（后续）
- 现货 → 杠杆/合约（扩展仓位模型与强平风控）
- 秒级/高频（撮合延迟、队列、限频策略升级）
- 链上（可选）
