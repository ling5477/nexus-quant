## V1：数字货币（当前主线）

### v1.0（Gate A）— 正确性底座（文档 + 骨架）
- 冻结域模型、状态机、事件契约、数值精度策略、恢复口径
- Postgres / Flyway 迁移规划
- auth / gateway 骨架与 traceId 透传约定
- 模块与依赖方向冻结（含 `nq-app` 启动载体）

### v1.1（Gate B）— 单交易所现货闭环（实现）
- 单交易所 Spot 的最小下单、撤单、成交、记账闭环
- 幂等、状态机、事实链、账本与恢复底座落地
- 最小风控与最小观测形成第一版实现

### v1.2（Gate C）— 多交易所接入与回放增强
- Adapter API 稳定，多交易所并行
- OKX / Binance 的 REST / WS 接入与归一映射
- 模拟盘、reconcile、recovery、WS 加速链路铺开
- GateC 解决的是“系统已经接上交易所并能跑起来”

### v1.3（Gate D）— 统一执行闭环与执行域硬化（已冻结）
- 统一执行入口、统一 adapter 契约与统一状态推进入口
- pre-trade 风控硬规则链
- 订单状态机硬化：本地状态与外部事实状态分层
- trade / ledger / position / account 快照联动
- reconcile / recovery / degrade / query-confirm 收敛
- GateD 解决的是“系统已经不是能跑，而是能冻结、能审计、能补偿、能验收”

### v1.4（Gate E）— 策略接入与调度编排（已冻结）
- 策略信号标准化接入
- 策略注册、启停、运行状态管理
- 调度窗口、串行化、去重与作业编排
- 执行结果回传与调度层联动
- GateE 解决的是“已有执行闭环之上，如何把策略层接进来并稳定编排”

### v1.5（Gate F）— 研究 / 回测 / 评估能力（已完成并冻结）
- 研究配置、回测配置、回测运行主链
- 模拟执行事实链与评估能力
- `publish` 接口与查询呈现补齐
- GateG 联调所需查询面与认证链已收口

### v1.6（Gate G）— 前端控制台与联调（当前阶段）
- 前端工程骨架
- 登录与鉴权守卫
- 布局、菜单与路由收口
- 策略 / 调度 / 运行页面
- 研究 / 回测 / 评估 / 发布页面
- 交易验证操作页
- Playwright 回归

### v1.x（后续）
- 现货 → 杠杆 / 合约（扩展仓位模型与风控）
- 秒级 / 高频优化（队列、限频、时延观测升级）
- 链上能力（可选）
