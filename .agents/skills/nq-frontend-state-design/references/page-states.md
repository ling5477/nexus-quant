# 页面状态与视觉检查

仅覆盖页面实际存在的状态：loading、empty、error、disabled、stale、权限不足、未配置。空态说明下一步，权限不足不能伪装成无数据。危险动作展示真实影响和必要确认，勿把所有按钮都升级为危险动作。

以决策优先级安排业务标识、状态、指标、操作与追踪信息。长技术详情可放详情区域；保留用户排障和风险判断所需字段。业务文案根据上下文具体化，不为了模板机械延长简单提示。

视觉检查围绕层级、间距、对齐、溢出、响应式、对比度和键盘焦点；使用现有设计 token，只在明确复用时提取组件。动效只帮助理解状态和反馈。

浏览器验证使用可用的适合工具。Playwright 用用户可见角色/标签定位，保持 fixture 稳定；行为无变化时不新增整套 E2E。登录、查询、详情、确认和失败反馈仅测试受影响的链路。
